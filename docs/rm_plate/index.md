# RM-OpenSG plate (through-thickness SG)

**MSG Reissner–Mindlin plate homogenization and 3-D dehomogenization** from a
through-thickness 1-D Structure Gene: laminate → the full $8\times8$ **ABDG**
plate law (Yu–Hodges–Volovoi VAM construction), and back — pointwise 3-D
stress, strain and displacement recovery from the 2-D plate solution.  The
plate analog of the VABS two-step beam workflow, validated component-by-
component against exact 3-D elasticity (Pagano cylindrical bending).

```{image} ../_img/rm_plate/conventions.png
:width: 85%
:align: center
```

## Quick start

```python
from opensg_jax.fe_jax.msg_rm_plate import rm_plate_msg
db = {"uni": {"E": [140e9, 9e9, 9e9], "G": [5e9, 5e9, 3e9],
              "nu": [0.3, 0.3, 0.3], "rho": 1550.0}}
r = rm_plate_msg(thick=[0.001]*4, angles_deg=[45, -45, -45, 45],
                 mat_names=["uni"]*4, material_db=db, fraction=0.5)
print(r["ABDG"])          # the 8x8 Reissner-Mindlin plate law
```

or entirely from the command line (no Python):

```bash
python -m opensg_jax.fe_jax.cli_rm_plate homo my_sg.yaml
```
