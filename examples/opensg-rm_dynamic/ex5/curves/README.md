# Example 5 history curves — what is here and how to change the plots

All plots in this folder are generated by **`make_curves9.py`** (the 9-component
sets in `with_FSDT/` and `without_FSDT/`) and **`make_curves.py`** (the original
Fig-5-style pair `w_center_*` / `sx_top_center_*`).  Copies of both scripts live
in this folder for reference; the *executed* originals are one level up in
`ex5/` (edit and run those).

Regenerate everything with (from the repo root, on the server):

```bash
~/miniconda3/envs/opensg_2_0/bin/python examples/opensg-rm_dynamic/ex5/make_curves9.py
```

No Abaqus run is needed — the scripts only re-read the `.dat` files already in
`ex5/Abaqus_results/`.

## The plots

Two sets, identical except that `with_FSDT/` adds the Abaqus-FSDT curve to the
displacement plots (a conventional shell run has no 3-D stress output, so the
stress panels there carry a note instead of a third curve).
`<comp>_step.png` = suddenly-applied held load, `<comp>_blast.png` = e^(−330t)
blast.  Time axis is displayed 0–8 ms; the `.dat` files keep the full 20 ms.

| plot | station | note |
|---|---|---|
| U1, U2, U3 | center node (a/2, b/2) | U1 = U2 = 0 by symmetry — shown with the numerical max annotated |
| S11, S22, S12 | center, top surface — label says z = h/2; the exact sample depth in both models is the top-ply centroid h/2 − t_ply/2 (the solid's outermost integration point) | S12 = 0 by symmetry, annotated |
| S13 | (0, b/2), mid-core z = 0 | RM every 50 μs, solid at its dumps |
| S23 | (a/2, 0), mid-core z = 0 | same |
| S33 | center, mid-core z = 0, dynamic momentum integral | **both models at the same time locations** (the solid dump instants; RM interpolated there) |

## Data files

- `histories_<kind>.dat` — OpenSG-RM at every 50 μs: `t[ms] U1 U2 U3[m] S11 S22 S33 S12 S13 S23[Pa]`, at the stations above.
- `solid_<kind>.dat` — Abaqus 3-D solid at its dump instants: `t[ms] S11 S22 S33 S12 S13 S23[Pa]`.

## How to change legend text, axis labels, styles

All in `ex5/make_curves9.py`:

- **Legend entries** — the strings `"Abaqus 3-D solid"`, `"OpenSG-RM"`,
  `"Abaqus FSDT"` in the displacement block (`for c, lbl in ((0,"U1"),…)`), and
  `lab_rm` / `"Abaqus 3-D solid"` in the stress loop (`for lbl, rmv, … in SPEC`).
- **Y-axis labels (the "curve titles")** — the fourth entry of each `SPEC` row
  (raw LaTeX strings, e.g. `r"$\sigma_{11}(a/2,b/2,h/2)$ [MPa]"`), and the
  `"%s at (a/2, b/2) [m]"` string for the displacements.
- **Line/marker styles** — the three dicts at the top: `STY_SOL` (dashed black
  ○), `STY_RM` (orange —□), `STY_FS` (green -.△).  `markevery=(offset, stride)`
  staggers the markers so they don't overlap.
- **Time window** — `ax.set_xlim(0.0, 8.0)` inside `one_plot()`.
- **Corner annotations** — the `note=` strings (symmetry-zero magnitudes, the
  FSDT no-3-D-stress note).

There are deliberately **no figure titles** — the LaTeX caption is the title.
